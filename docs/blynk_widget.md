# blynk_widget.h

## Purpose
Defines Blynk virtual pin aliases used by client code.

## Defined Pins
- `GAUGE_HOUSE` -> `V2`
- `TEMPV4` -> `V4`
- `TEMPV6` -> `V6`
- `TEMPV5` -> `V5`
- `R_DIV` -> `V3`
- `BLINK_TST` -> `V9`
- `VRECOV` -> `V19`
- `VFAIL` -> `V20`
- `VRETRY` -> `V34`

## Usage
Include this header where Blynk virtual pins are written to improve readability and avoid duplicated literal pin IDs.
